## 2. Agent 状态机流程图（LangGraph StateGraph）

```mermaid
stateDiagram-v2
    [*] --> agent: START

    state agent: _agent_node
    note right of agent
        1. 上下文压缩检查 (85% 阈值)
        2. 同步文档/附件上下文
        3. 构建 System Prompt (状态快照)
        4. LLM 决策 (ReAct)
    end note

    agent --> tools_condition: LLM 回复

    state tools_condition <<choice>>
    tools_condition --> END: 无工具调用, 直接回复
    tools_condition --> pre_tools: 有工具调用

    state pre_tools: _pre_tool_node
    note right of pre_tools
        HITL 检查:
        - generate_section 调用?
        - auto_mode = True? 跳过
        - interrupt() 暂停等待用户
    end note

    pre_tools --> HITL_PAUSE: generate_section 且非 auto_mode

    state HITL_PAUSE {
        [*] --> 等待用户确认
        等待用户确认 --> approve: 用户确认
        等待用户确认 --> edit: 用户修改
        等待用户确认 --> reject: 用户拒绝
        approve --> [*]: Command(resume=approve)
        edit --> [*]: Command(resume=edit)
        reject --> [*]: Command(resume=reject)
    }

    HITL_PAUSE --> tools: resume 恢复
    pre_tools --> tools: 非 HITL 工具, 直接执行

    state tools: ToolNode
    note right of tools
        执行工具:
        search_kb / search_attachment
        generate_section / revise_section
        design_outline / write_chapter
        summarize_section / build_docx
        web_search / analyze_document
    end note

    tools --> after_tools

    state after_tools: _after_tools_node
    note right of after_tools
        结果写回 state:
        - generated_sections 更新
        - outline / outline_status 更新
        - document_status 更新
    end note

    after_tools --> agent: 循环继续
    END --> [*]
```

## 5. HITL 人机协同交互时序图

```mermaid
sequenceDiagram
    actor U as 用户
    participant F as 前端 agent.html
    participant A as Agent Engine
    participant L as LLM Ollama
    participant T as ToolNode
    participant S as SqliteSaver

    U->>F: 输入消息
    F->>A: POST /agent/projects/:id/messages

    Note over A: 加载状态 (SqliteSaver 检查点恢复)
    A->>S: aget_checkpoint(thread_id)
    S-->>A: 返回历史状态

    Note over A: 构建 System Prompt + 上下文压缩
    A->>L: ainvoke(messages + tools)
    L-->>A: tool_calls: [generate_section]

    Note over A: _pre_tool_node 检测到 generate_section
    Note over A: auto_mode = false

    A->>A: interrupt(generate_section_approval)
    A->>S: 保存检查点 (暂停状态)
    A-->>F: SSE event: on_interrupt<br/>{section_name, message}

    F-->>U: 弹出确认对话框<br/>[确认] [修改] [拒绝]

    alt 用户确认 (approve)
        U->>F: 点击确认
        F->>A: POST /agent/.../resume<br/>{action: approve}
        A->>S: 加载暂停检查点
        A->>A: Command(resume=approve)
        A->>T: 执行 generate_section
        T->>L: 调用 chapter_agent 生成
        L-->>T: 返回章节内容
        T-->>A: ToolMessage(章节内容)
        A->>S: 保存检查点
        A-->>F: SSE: 章节内容 + tool_result
        F-->>U: 显示生成章节
    end

    alt 用户修改 (edit)
        U->>F: 修改指令后提交
        F->>A: POST /agent/.../resume<br/>{action: edit, content: 修改内容}
        A->>A: Command(resume=edit)
        A->>T: 执行 generate_section (带修改)
        T-->>A: 返回修订后章节
        A-->>F: SSE: 修订章节
    end

    alt 用户拒绝 (reject)
        U->>F: 点击拒绝
        F->>A: POST /agent/.../resume<br/>{action: reject}
        A->>A: Command(resume=reject)
        A->>A: 跳过该章节
        A-->>F: SSE: 跳过通知
    end

    Note over A,S: 全程状态自动持久化<br/>支持进程重启后恢复
```
