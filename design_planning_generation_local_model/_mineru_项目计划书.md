========== 第 4 页 ==========

第1章 概述 Introduction

1.1 项目基本信息，目的，范围 Project Basic Information, Purpose and Scope

目的：本项目目的是在 GS1-P2 产品上进行性能优化。

范围：本项目的范围是GS1-P2型持续葡萄糖监测系统相关组成部分，包括传感器套装和持续葡萄糖监测系统软件。

项目代号: GS1 plus。

1.2 文档结构 Documents Structure

项目计划规定项目的主体架构、主要活动、主要评审节点和里程碑节点。子计划以此为基点，定义其主要活动、主要交付物和资源需求。

1.3 术语定义 Definitions

本节对本文档所使用的项目专用术语进行说明。

GS1-P2 型：“GS”为“Glucose Sensing”即“葡萄糖传感”的缩写，表明产品类别。“1”是产品序列号，“GS1”为我司第一款同类产品，“P”代表“加强与延伸”，表明是在我司研发的第一款产品上的加强与延伸。

========== 第 9 页 ==========

第4章 关键假设、依赖和约束 Key Assumptions, Dependency and Constraint

影响项目开发计划的关键因素和假设：

与其他项目的关系

■ 本项目目的是在 GS1-P2 产品上进行性能优化。

需求

■ 本项目开发过程中，不会出现内外部因素导致产品定义和预期用途发生重大改变，导致项目范围或目标出现重大调整，从而引起项目计划必须做出重大调整。

时间要求

ID 造型必须要按时完成审核，系统设计必须于同期完成物理部署的相关设计，以使机械、硬件等方向开展详细设计和启动手板样机制作。在详细设计过程中，不会发生 ID 造型和系统设计的重大调整。否则项目进度将整体向后顺延。

资源约束

■ 供应链必须配合研发与开发过程同步进行物料准备工作，保证物料按期交付支持各版本样机装机。尤其应注意对长周期、定制件等关键物料和供应商的管理。否则将影响样机装机计划，进而导致项目的整体进度延期。

设计

■ 硬件、软件、机械等方向必须制定详细的设计开发计划，并密切跟踪，相关合作方应按计划交付产品和服务。

➢ 职能控制

项目团队成员均能胜任项目对该角色的职能要求，包括专业技能、质量意识、管理能力等；各职能部门能够根据项目计划及时投入资源，满足项目的人力资源投入需求。

各职能部门主管严格管控评审等质量活动，保证项目开发过程的质量；及时为项目组成员提供开发流程、专业技能的培训和指导，及时跟进解决影响项目进度和质量的关键问题。

▶ 法规

在项目开发过程中，国内外法规、政策和公司政策不会出现重大变化和调整。如果法规、政策出现变化和调整，项目组将及时评估和修订开发计划。

========== 第 13 页 ==========

第7章 功能部门的计划 Functional Department Plan

7.1 市场 Marketing

GS1-P1 和 GS1-P2 型持续葡萄糖监测系统面向国内市场发布。

市场推广策略延续当前解决方案项目的推广策略，升版相关内容；研发提供产品资料，协助市场总结产品亮点，确定核心宣传诉求，制定推广方案。学术方面以专科化方案等为核心，展开专家、窗口医院、学术文章、学术推广会方面工作。

7.2研发 R&D

研发部按照质量管理体系的流程文件要求，有序按照设计输入、设计展开、设计验证、设计确认、设计转换的相关阶段开展工作，并引入适宜的评审。确保设计需求充分得到确认和满足。

7.3 生产 Production

外购或由外协加工主要零部件，在硅基传感生产线组装、测试、包装。整机制造使用现有的场地。开发装配工艺和整机测试工装支持生产，通过工序优化及工装使用降低各工位操作难度，提高生产质量和效率，降低生产成本。

7.4 质量 Quality

质量部门进行研发、采购、生产、放行、过程确认、基础设施管理、内审、管理评审等全质量体系流程的符合性控制。组织维护和建立符合法规及公司要求的体系文件的基础上，现场进行来料、过程及最终产品的检验及放行制度，严格控制产品质量。

7.5供应链 Supply Chain

供应商资源方面

根据物料类进行资源整合，打包供应：包括PCBA、导引针、塑胶开模件、硅胶件、包材。

进度方面

重点管控定制件供应商的开发计划监控和定期通报。

成本方面

开发初期，通过伟创力等供应商早期介入，优化设计控制成本；
