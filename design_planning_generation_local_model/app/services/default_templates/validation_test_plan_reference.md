测试目的

本测试方案的目的是验证CGM持续葡萄糖监测系统GK5发射器P-PCBA（NRF）的各项性能是否满足设计需求。

范围

本测试方案仅适用于CGM持续葡萄糖监测系统三电极发射器PCBA。

GK5系列集成式持续葡萄糖监测系统C端、B端使用相同的发射器PCBA和发射器软件

适用的GK5系列规格型号：GK5、GK5S、GK5A 。

GK5系列集成式持续葡萄糖监测系统C端、B端使用相同的发射器PCBA和发射器软件

GK5系列（C端）的所有规格型号（包括GK5）、GK5系列（B端）（包括GK5S、GK5A）均使用同一个发射器软件，不同型号间的使用天数差异、血糖更新频率差异，将通过在产测时烧录不同的产品线进行实现。

测试说明

GK5 发射器软件支持15天1分钟1笔数据存储，代表型号为GK5，故本次发射器测试将选取发射器软件默认配置（GK5 ）作为代表性产品，按测试方案进行全面测试；

测试说明

由于GK5、GK5S、GK5A版本的底软功能一致，仅续航天数有差异；底软与APP的通信协议相同，业务逻辑相同，因此使用GK5版本的测试方案和报告覆盖GK5S、GK5A版本的测试方案和报告
